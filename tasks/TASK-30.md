# TASK-30: ダッシュボードKPIカードとヘッダーのUI刷新

## 目的

ダッシュボードの上部を横並び4枚のKPIカードと、タイトル・ボタンを含むヘッダーに刷新する。

## 背景

現状のダッシュボードはKPI項目が縦並びのシンプルな表示。
設計書スクリーンショットに合わせて以下のレイアウトへ変更する。

```
[ ヘッダー: プロジェクト全体サマリー  [レポート出力] [⚙] ]

[ 総利用可能工数(月) ] [ 使用済み工数     ] [ 最終使用予想工数  ] [ 残工数(予算・予想) ]
[     160h           ] [ 0h  消化率0%     ] [ 0h  予算比0%      ] [      160h          ]
```

## 作業内容（TDD）

### テストを先に書く

- ヘッダーに「プロジェクト全体サマリー」「レポート出力」ボタンが存在する
- KPIカード4枚が横並びで存在する（id: `kpi-total`, `kpi-actual`, `kpi-predicted`, `kpi-remaining`）
- `dashboard:init` / `dashboard:update` 受信時に各カードが正しい値で更新される
- 消化率（`kpi-actual` 配下）= `actual / total * 100` が表示される
- 予算比（`kpi-predicted` 配下）= `predictedTotalEffort / total * 100` が表示される

### 実装

- `dashboard.js` の `renderHtml()` を刷新し、ヘッダーと4枚カードのHTMLを生成する。
- `render(state)` 関数を更新し、消化率・予算比を計算して DOM へ反映する。
- CSS はインライン `<style>` タグで定義する（外部ファイル不要）。

## DoD（完了条件）

- `dashboard:init` を受けると4枚カードに正しい値が表示される。
- 消化率・予算比がパーセント表示される。

- [ ] 消化率・予算比が計算されて表示される
