# TASK-32: スプリントバーンダウンチャートの視覚改善

## 目的

バーンダウンチャートをスクリーンショットのデザインに合わせて刷新する。

## 変更内容

| 要素 | 現状 | 新デザイン |
|---|---|---|
| 実績ライン | 青（`#007acc`）、太さ2 | 黄緑（`#c8e06b`）、ドット付き |
| 予測ライン | オレンジ（`#f39c12`）、破線 | グレー（`#888`）、破線 |
| チャートサイズ | 640×220 | 幅100%・高さ220（レスポンシブ） |
| 背景 | なし | ダークグレー背景に合わせた軸グリッド線 |
| ラベル | なし | Y軸に目盛り数値、X軸に日付/日番号 |

## 作業内容（TDD）

### テストを先に書く

- 実績 polyline の `stroke` が黄緑系の色になっている
- 予測 polyline の `stroke` がグレー系の色になっている
- バーンダウンデータがある場合、Y軸グリッド線が描画される（`<line class="grid">` が存在する）
- X軸ラベル（`<text class="x-label">`）が各データポイントに対して描画される

### 実装

- `dashboard.js` の `drawBurndown(state)` 関数を更新する。
- 実績ラインの色・ドットマーカー（`<circle>`）を追加する。
- 予測ラインの色を変更する。
- Y軸グリッド線と X軸ラベルを追加する。
- SVG の `viewBox` を設定してレスポンシブ対応にする。

## DoD（完了条件）

- バーンダウンチャートがスクリーンショットの配色・スタイルで描画される。

- [ ] Y軸グリッド線が描画される
