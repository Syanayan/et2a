# 工数管理 VS Code 拡張 要求仕様書

## 1. プロジェクト概要
本拡張機能は、VS Code 上でプロジェクト単位の工数（見積・実績・予測）を管理し、開発者がエディタを離れることなく進捗状況を把握できるようにすることを目的とする。あわせて、CI/CD やタイムトラッカー等の外部ツールとのデータ連携を可能にする。

---

## 2. 機能要件

### 2.1 プロジェクト管理

#### 2.1.1 プロジェクト分離
- プロジェクト単位で工数設定を保持する。
- 設定は `kousu.config.json` 等の JSON ファイルで管理する。

#### 2.1.2 基本設定項目
各プロジェクトで以下を設定可能とする。
- プロジェクト名
- 着工日
- 納期
- 総工数（人日または時間）
- バッファ（予備工数）
  - 総工数とは別枠（外数）または内数として設定可能
  - リスク対応用として扱う

### 2.2 工数計算・予測

#### 2.2.1 実工数管理
- 実際に消費した工数（実績工数）を継続的に蓄積・更新する。

#### 2.2.2 残日数計算
- 納期までの残稼働日数を自動計算する。
- 計算時は以下を除外する。
  - 土日
  - 会社休暇日（設定可能）
  - 担当者（設定した人）の個人休暇日（設定可能）

#### 2.2.3 予測機能（トレンド分析）
現在の消費ペースに基づき、以下を算出・表示する。
- 予想消費工数（完了までに必要な総工数予測）
- デッドライン予測（工数が枯渇する想定日）

#### 2.2.4 警告表示
以下の条件で VS Code 上にアラートを表示する。
- 予測消費工数が総工数を超過する場合
- 実績工数がバッファ領域に入った場合

### 2.3 リソース管理

#### 2.3.1 動的メンバー追加
- プロジェクトメンバーを随時追加できる。

#### 2.3.2 個別稼働設定
- メンバーごとに「1日の消費予定工数（稼働率）」を設定できる。

### 2.4 外部連携（API設計）

#### 2.4.1 外部からの更新
- 外部アプリ（CI/CD、タイムトラッカー等）から、総工数・実績工数などを更新できるインターフェースを提供する。

#### 2.4.2 外部への提供
- 外部アプリが、本拡張機能内の進捗データを取得できるインターフェースを提供する。
- 取得対象例:
  - 進捗率
  - 予測終了日

#### 2.4.3 休暇日データ連携
- 会社休暇日および担当者の個人休暇日を、外部アプリまたは外部ファイルから取得・同期できるようにする。
- 取り込み方式は少なくとも以下を想定する。
  - API経由（例: 社内勤怠/カレンダーシステム）
  - ファイル経由（例: JSON/CSV）
- 連携した休暇日は残稼働日数計算および予測計算に反映する。

### 2.5 UI/UX

#### 2.5.1 VS Code サイドバー
- プロジェクト一覧を表示する。
- 各プロジェクトの簡易ステータスを表示する。

#### 2.5.2 Webview ダッシュボード
- バーンダウンチャート
  - 総工数、バッファ、実績の推移を可視化する。
- 進捗ゲージ
  - 進捗率を視覚的に表示する。

## 3. 追加仕様（リスク管理・バッファ）

### 3.1 バッファ（予備工数）の定義
- バッファは、以下のいずれかの形式で設定可能とする。
  - 総工数の内数
  - 総工数の外数

### 3.2 警告フェーズの引き上げ
- 実績工数が `総工数 - バッファ` を超過した時点で、警告フェーズを「注意」に引き上げる。

### 3.3 残日数・枯渇予測の二系統表示
- 残り工数がマイナスになるまでの日数について、以下の 2 パターンを併記する。
  - バッファを含めない場合
  - バッファを含める場合

## 4. データ構造案（`kousu.config.json`）

```json
{
  "projectId": "p-001",
  "projectName": "新システム開発",
  "schedule": {
    "startDate": "2024-05-01",
    "endDate": "2024-08-31",
    "holidays": ["2024-08-13", "2024-08-14", "2024-08-15"],
    "holidaySources": {
      "company": { "type": "file", "path": "./holidays/company-holidays.json" },
      "member": { "type": "api", "endpoint": "https://example.local/api/member-holidays" }
    }
  },
  "effort": {
    "total": 100,
    "buffer": 15,
    "actual": 45
  },
  "members": [
    { "name": "UserA", "dailyEffort": 1.0, "personalHolidays": ["2024-08-20"] },
    { "name": "UserB", "dailyEffort": 0.5, "personalHolidays": [] }
  ]
}
```

### 4.1 項目補足
- `projectId`: プロジェクト識別子
- `projectName`: プロジェクト名
- `schedule.startDate`: 着工日
- `schedule.endDate`: 納期
- `schedule.holidays`: 会社休暇日配列（任意）
- `schedule.holidaySources`: 休暇日の取得元設定（API/ファイル）
- `effort.total`: 総工数
- `effort.buffer`: 予備工数
- `effort.actual`: 実績工数
- `members[].name`: メンバー名
- `members[].dailyEffort`: 1日あたり予定工数（稼働率）
- `members[].personalHolidays`: 担当者個人の休暇日配列（任意）
